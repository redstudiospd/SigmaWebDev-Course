 2. Core Web Vitals:
 Core Web Vitals are Google’s measurements of how fast, responsive, and visually stable a website feels to users.

 a. Cumulative layout shift(CLS): CLS is a measure of the largest burst of layout shift scores for every unexpected layout shift that occurs during the entire lifecycle of a page.
 b. Largest contentful page(LCP): LCP reports the render time of the largest image, text block, or video visible in the viewport, relative to when the user first navigated to the page.
 c. Interaction to next paint(INP): INP (Interaction to Next Paint) measures how quickly a webpage visually responds to user interactions such as clicks, taps, and key presses.
 good:<200ms

 3. Generating a lighthouse report:
 It helps to provide insights on improving the website's efficiency and user experience.
 It audits the website based on the core web vitals and generates a report and scores it
 based on core web vitals and flags areas of improvements. It also only supports https/http
 based sites for audit not from the local file path. It is a great tool but only reserved in
 chromium based browsers like brave and chrome.

 4. Meta Description and keywords:
 a. Meta Description: A meta description is a brief HTML summary of a webpage that search engines may display in search results to describe its content.
 It also increases the probability of your site being shown in the results at the top. But it depends totally on the search engines(like google, bing, etc).

 b. Meta keywords: Meta keywords are HTML terms once used to tell search engines what a webpage is about, but major search engines generally no longer use them for ranking.
 Meta keywords are now deprecated.
