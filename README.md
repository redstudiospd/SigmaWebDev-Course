## 🧠 What I'm Learning

### 🟠 HTML: the skeleton
The structure of every web page. HTML tells the browser *what* things are: headings, paragraphs, images, links, forms.

- Semantic tags (`header`, `nav`, `main`, `section`, `footer`)
- Links, images, lists, tables
- Forms and inputs
- Media elements (`audio`, `video`)
- Attributes, IDs and classes

### 🔵 CSS: the style
Makes the skeleton look good. Colors, spacing, layouts, animations.

- Selectors and specificity
- Box model (margin, border, padding)
- Flexbox for one-dimensional layouts
- Grid for two-dimensional layouts
- Transitions, keyframe animations, responsive design with media queries

### 🟡 JavaScript: the brain
Makes pages interactive. Logic, data, and reacting to the user.

- Variables, data types, operators
- Conditionals and loops
- Functions, arrays, objects
- DOM manipulation and events
- Async JS (callbacks, promises, `async`/`await`) and `fetch`

### ⚛️ React: the UI engine
A library for building UIs out of reusable components, so the screen updates automatically when data changes.

- Components and props
- State with `useState`
- Side effects with `useEffect`
- Conditional rendering and lists with keys
- Hooks and component composition

### 🧩 JSX: HTML inside JavaScript
The syntax React uses to describe UI. It looks like HTML but compiles to JavaScript.

- Writing markup inside JS files
- `{}` expressions to embed JS values
- `className` instead of `class`
- Fragments (`<>...</>`) and single root rules
- Event handlers like `onClick`

### 🟢 Node.js: JavaScript on the server
Runs JS outside the browser, so I can build backends, APIs, and tools.

- Modules (CommonJS and ES modules)
- File system (`fs`) and `path`
- npm and `package.json`
- Building servers and handling requests
- Environment variables

### 🌊 Tailwind CSS: utility-first styling
Style directly in your markup with small utility classes instead of writing separate CSS.

- Utility classes (`p-4`, `text-center`, `bg-blue-500`)
- Responsive prefixes (`md:`, `lg:`)
- State variants (`hover:`, `focus:`)
- Flex and grid utilities
- Customizing via the config file
